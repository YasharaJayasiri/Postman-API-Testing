 # Postman API Testing Project

This is a beginner-level API testing project created using **Postman**.  
It uses the public API [ReqRes](https://reqres.in/) to demonstrate how to test RESTful endpoints with different HTTP methods.

## Project Structure
The collection is divided into three main folders:
- **POST** – Create and register users
- **GET** – Retrieve single and multiple user details
- **PUT** – Update existing user information

## Test Execution
- The entire collection was run together with **3 iterations** and a **5ms delay** between requests.

### Project Purpose
This project was created as part of my QA learning journey to understand how REST APIs work and how to test them using Postman.
